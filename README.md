# TRISP

The GitHub repo associated with the manuscript titled "The Goldilocks zone for 3T MRS studies using semi-LASER: Determining the optimal balance between repetition time and scan time."

Here, you can find all of the fit outputs in the folder "Interactive_TRISP_data" and the shell script used to run the analysis in FSL MRS.

This is the repo that is the basis for an interactive application created in Python's streamlit. The app plots many things beyond what is included in the manuscript and is heavily interactive so you can see plotted exactly what you want to see!

Go to https://tr-in-mrs.streamlit.app/ to see the app in action!
